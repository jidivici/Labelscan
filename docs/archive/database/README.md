# Archived database references

These SQL files are historical snapshots. They were once convenient design references,
but they are not an executable or complete description of the current database.

Use these sources for development today:

- [`server/migrations/`](../../../server/migrations/) for the ordered, executable schema
  history;
- the [database reference](../../database/DATABASE.md) for a readable model overview;
- the backend integration tests for transaction, tenancy, and immutability behavior.

The archived `schema.sql` snapshot and handwritten extracts under `migrations/` are kept
only to explain older discussions and links.
