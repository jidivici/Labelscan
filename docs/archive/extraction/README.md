# Archived extraction references

This directory preserves the version 1 extraction schema and its small example set. They
predate the current business-profile contracts and must not be used to validate new
captures.

For current development, use the backend extraction models and tests together with the
[prompt contract](../../extraction/PROMPT-CONTRACT.md), [pipeline architecture](../../pipeline/PIPELINE-ARCHITECTURE.md),
and [evaluation guide](../../pipeline/eval-suite.md).
