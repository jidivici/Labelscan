# Démonstration LabelScan

La démo comprend neuf arrivages fondés sur les photographies d'[images](images/). Le [manifeste v2](manifest.v2.json) associe chaque image à son SHA-256 et décrit les champs présents, absents ou ambigus, avec leur évidence.

Le [seed](../scripts/seed_demo.py) construit les exemples catalogue. Les tests correspondants sont dans [test_demo_arrivals.py](../tests/test_demo_arrivals.py).

Le contrat d'extraction est présenté dans la [documentation technique](../../docs/TECHNICAL-DOCUMENTATION-FR.md#contrat-ia).
